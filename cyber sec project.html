Architecture

Five modules, one risk engine.

Every detector is independent and stateless on the wire — each simply passes a scored event to the AI Risk Engine, which tracks entity-level risk, correlates related events into threat clusters, and raises alerts once a score crosses the line.

MODULE 01 · IsolationForest

Network anomaly detection

Scores raw traffic samples — request rate, port spread, failed connections, packet size, duration, bytes in/out — against a learned baseline of normal behavior.

POST /api/network/analyze
MODULE 02 · RandomForest

Phishing & malicious URL detection

Extracts lexical and structural features from a URL, sender, or message body and classifies it across a phishing risk spectrum.

POST /api/phishing/check
MODULE 03 · k-anonymity

Breach & account exposure

Checks an identifier against known breach sources. Passwords are hashed locally and only a 5-character prefix ever leaves the process — full hash and plaintext are never stored.

POST /api/breach/check
MODULE 04 · UEBA

User & entity behavior analytics

Learns a rolling baseline per user — login hour, region, device fingerprint — and flags logins that break the pattern.

POST /api/behavior/login
CORE · Correlation

AI risk engine

Persists every event, updates an exponentially-weighted entity risk profile, clusters related high-risk events within a 30-minute window, and raises alerts at score ≥ 60.

→ record_event()
INTERFACE · NLQ

AI security copilot

Answers plain-language questions grounded in stored events and alerts — "why is this IP suspicious," "summarize the last 24 hours."

POST /api/copilot/ask
